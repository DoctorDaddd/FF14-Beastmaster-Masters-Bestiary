# FF14 – Beastmaster – Master's Bestiary

一个离线运行的 FF14 魔兽图鉴工具，用来查看魔兽资料并记录捕获进度。

## 功能

- 收录 50 种魔兽，显示编号、图片、等级、栖息地区和坐标。
- 点击条目查看离线地图、栖息位置红圈、地下入口及获取说明。
- 支持名称搜索、地区筛选、全部／未捕获／已捕获筛选。
- 支持编号、等级和地区排序。
- 勾选“已捕获”后自动保存进度；也可以使用“隐藏已捕获”快速查看待收集条目。
- 地区内的魔兽全部捕获后，地区下拉选项会显示绿色勾号。
- 附带网页标签图标、启动快捷方式和移动端布局。

## 使用方法

保留整个仓库目录，双击 `启动魔兽图鉴.lnk`，或直接打开 `index.html`。运行时不需要服务器或网络连接。

捕获进度保存在当前浏览器的本地存储中。请固定使用同一个浏览器和文件位置，以便保留进度。

## 数据来源

图鉴资料参考[灰机 Wiki 魔兽图鉴](https://ff14.huijiwiki.com/wiki/魔兽图鉴)，地图和坐标标记依据 Wiki 地图数据制作并随仓库离线保存。40 号妖魂的 7 级等级、地下栖息位置和入口坐标由用户补充。
